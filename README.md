## 📋 Описание проекта и выполненных требований

### 1. Размещение и доступность
* Размещено на **GitHub Pages**: [https://paxls.github.io/portfolio/](https://paxls.github.io/portfolio/).
* Сгенерирован и встроен **QR-код** для быстрого перехода с мобильных устройств (`assets/qr-code.svg`, `assets/qr-code.png`).

### 2. Контент и уникальность
* Текст написан вручную (более 3 000 символов, при минимальном требовании 300), содержит актуальную информацию о специализации (Frontend & Game Development, студент ГУАП), стеке технологий и реальных проектах.
* Адаптивная векторная графика:
  * Оригинальный аватар разработчика в формате SVG (`assets/avatar.svg`);
  * 5 векторных иллюстраций кейсов (`assets/project1.svg` — `project5.svg`);
  * Интерактивные SVG-иконки для всех технологий, соцсетей и элементов интерфейса.

### 3. Адаптивность и ручная доработка
* Полная адаптивность под любые разрешения: от мобильных устройств (320px) до Full HD и 4K экранов.
* Использованы современные технологии верстки: CSS Grid (2-3 колонки с динамическим переносом) и Flexbox.
* Адаптивное бургер-меню для мобильных экранов.

### 4. Навигационное меню
* Семантический тег `<nav>` со ссылками `<a href="#section-id">`:
  * `Главная` (`#hero`)
  * `Обо мне` (`#about`)
  * `Портфолио` (`#portfolio`)
  * `Стек навыков` (`#skills`)
  * `Контакты` (`#contact`)
* Плавная прокрутка (`scroll-behavior: smooth`) с компенсацией высоты фиксированного хедера (`offset`).
* Активное состояние пунктов меню при прокрутке страницы (ScrollSpy).

### 5. Галерея изображений (Портфолио)
* Раздел с 5 тематическими проектами, организованными в адаптивную CSS Grid сетку.
* Фильтрация проектов по категориям: «Все», «Веб-разработка», «GameDev», «UI/UX Дизайн».
* Модальное окно (Lightbox Modal) для подробного просмотра каждого проекта с описанием, метриками и стеком.

### 6. Форма обратной связи
* Семантическая форма `<form>`, поля `<input type="text">`, `<input type="email">`, `<textarea>`.
* Валидация Email на стороне клиента: строгая проверка на наличие `@` и доменной зоны.
* Интерактивная валидация полей в реальном времени с подсветкой ошибок и выводом подсказок.
* Анимированное всплывающее уведомление (Toast) об успешной отправке заявки.

### 7. Футер сайта
* Семантический тег `<footer>` с CSS-стилизацией.
* Копирайт с динамическим текущим годом (`© 2026 Александр Павленко (AXL). Все права защищены.`).
* Векторные кликабельные иконки соцсетей: GitHub, Telegram, VK, Email.
* Кликабельный номер телефона (`tel:+79991234567`) и email (`mailto:pavlenko.aleksandr0708@gmail.com`).

### 8. Дополнительные фичи (Вау-эффект)
* **Dark / Light тема**: переключатель тем с сохранением выбора пользователя в `localStorage`.
* **Эффект печатной машинки** (Typing effect) в Hero-секции.
* **Кнопка "Наверх"** с плавным появлением при скролле.
* **Быстрое копирование ссылки** на сайт в один клик.
